## URL SHORTNER

Built an end-to-end web app where users can shorten URLs and manage them securely. short url generater which converts your lengthy URL in shorter urls.

## Demo

- [**LIVE LINK**](https://url-shortner-three-silk.vercel.app/)




## Tech Stack
- **React Js** and **Tailwind CSS** for responsive and scalable front end.
- **axios** to handle the API requests
- **Node.js** with **Express** server
- Database:**MONGODB** deployed it using Mongodb atlas.
- Authentication: **JWT** access tokens 
- Environment Management: **dotenv**
- Deployment: **Docker**, and hosted on **Render** and **vercel**.



## setup & Installation

1. Clone the repo:
```bash
git clone https://github.com/imharishpatil/URL-SHORTNER.git
```
2. Install dependencies:
```bash
npm install
# or
yarn install
```
3. Configure environment variables

4. Run locally:
```bash
npm run dev
# or
yarn dev
```
5. The API server should be running at http://localhost:4000 (or as configured)
